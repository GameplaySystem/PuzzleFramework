## Design Decisions

- Phase 2 remains prototype-owned inside `DropAwayPrototype`; no framework editor generalization is included in this slice.
- The primary editor workflow is now the dedicated `DropTheManLevelEditor` play-mode scene rather than selected-object SceneView tooling.
- The editor continues to author data only and must not become a runtime spawning or gameplay play/test path.
- Hole placement validation stays structural only in this slice: board bounds, blocked cells, stickman overlap, and hole-footprint overlap are rejected, while gameplay meaning remains outside the editor shell.
- The first export path reuses the existing prototype JSON schema/helper rather than duplicating serializer rules inside the HUD.
- The first import path also reuses the existing prototype JSON schema/provider path and only applies imported data after validation succeeds so broken files do not partially mutate the current authored scene state.
- Phase 4A keeps runtime spawning prototype-owned in `DropAwayPrototype`; it reuses the existing gameplay runtime path and scene adapters instead of adding a framework spawner or an editor one-click test bridge.
- The first runtime-spawning slice clones scene-local hole and stickman templates in the gameplay test scene rather than introducing a polished prefab pipeline.
